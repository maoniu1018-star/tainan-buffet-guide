# 寧寶貓的月光冒險

獨立的 HTML5 像素闖關遊戲，支援手機觸控與桌面鍵盤。

## GitHub Pages 部署
1. 在 GitHub 儲存庫 Settings → Pages。
2. Build and deployment 選擇 Deploy from a branch。
3. Branch 選 main，資料夾選 /(root)，儲存。
4. 遊戲網址會是 `https://maoniu1018-star.github.io/tainan-buffet-guide/ningbao-pixel-adventure/`。

注意：Pages 發佈設定可能需要數分鐘才生效。此遊戲檔放在獨立資料夾，不會覆蓋主網站首頁。
