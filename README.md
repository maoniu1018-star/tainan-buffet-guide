# 台南吃到飽｜Buffet、火鍋、燒肉、自助吧價格大全

GitHub Pages 靜態網站。請將本資料夾根目錄的 `index.html` 與 `data.json` 一起放在 Repository 根目錄。

## 核心功能
- 完整平日／晚餐價目表
- 兒童費用、服務費、備註
- 搜尋、行政區、類型、預算、排序
- Google Maps
- 官方網站／訂位連結（有資料才顯示）
- 製作者 Chung NING／Instagram

## 部署
GitHub → Settings → Pages → Deploy from a branch → `main` → `/ (root)`。
